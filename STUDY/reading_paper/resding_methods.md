
| 颜色        | 含义                      | 用途   |
| --------- | ----------------------- | ---- |
| 🟡 Yellow | Problem / Motivation    | 背景   |
| 🟩 Green  | Key Idea / Contribution | 核心方法 |
| 🟦 Blue   | Architecture / System   | 系统结构 |
| 🟧 Orange | Results / Numbers       | 实验结果 |
|           |                         |      |
| 🟥 Red    | Limitations             | 不足   |
| 🟪 Purple | Concepts                | 重要概念 |
| ⚪ Gray    | Related work            | 扩展文献 |

### 第一轮，10–15 分钟扫读

只看这些部分：

- **Title**
- **Abstract**
- **Introduction 前 1–2 页**
- **系统架构图 / block diagram**
- **结论**
- **最大的结果图或表**

看完后，立刻写三行：

- 这篇解决什么问题？
- 它的核心 idea 是什么？
- 最重要的结果数字是什么？

### 第二轮，20–30 分钟补结构

再看：

- Motivation / Background
- Architecture / Design
- Evaluation 开头和总结

这轮只要把论文的逻辑串起来：

**瓶颈 → 设计 → 为什么有效 → 实验结果**

### 第三轮，按需补细节

只有当你们组后面决定这篇会重点讲，你再去补：

- 具体模块
- data mapping
- timing / area / power 细节
- 更复杂的图表
