5 Improving Dynamic Programming for Knapsack Problems
### Project Description

In Knapsack problem, we are given n items with profits p1​,…,pn​ and weights w1​,…,wn​, and a knapsack with capacity c. Our goal is to find a subset of items so that their total weight does not exceed c and their total profit is maximized.

This problem can be solved in Θ(nc) time using standard dynamic programming. For 0≤i≤n, and 0≤j≤c, let P[i][j] be the maximum profit one can achieve using the first i items and a knapsack with capacity j. (For simplicity, we assume that P[i][j]=−∞ if for all j<0). We have the that

- P[0][j]=0 for all j
- P[i][j]=max{P[i−1][j],P[i−1][j−wi​]+pi​} for all i≥1 and all j.

Solving the recurrence gives the optimal value of Knapsack.  
Note that even in the best case, this algorithm needs as much as Θ(nc) time, and this is unpleasant in practice.

Chapter 3.4 of the book in the Reference provides an alternative implementation of the dynamic programing algorithm, which has a better best-case running time when combined with a pruning idea.

Chapter 3.5 of the book provides an idea for further improvement of the dynamic programming algorithm. You may implement it and compare it to the other two algorithms. Bonus will be granted depending on the quality of your work.
