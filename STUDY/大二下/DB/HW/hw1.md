Describe at least three tables that might be used to store information in a social networking system such as Facebook.

1. **Users Table**: A table that stores user information, including username, email, password, phone number, and other basic profile details.
    
2. **Friends Table**: A table that stores friendship relationships between users, including the IDs of the two users and the status or time of the friendship.
    
3. **Posts Table**: A table that stores posts created by users, including the post content, the user who created it, and the timestamp of the post.
