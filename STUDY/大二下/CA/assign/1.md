# 🟦 Slide 20（20s）

> Let’s first understand / why attention becomes the **bottleneck**. //

👉（看观众，不要看PPT）

> In autoregressive inference / attention is dominated by **GEMV** instead of GEMM, / which leads to very **low arithmetic intensity**. //

> At the same time / large **KV matrices** are repeatedly accessed. //

👉（稍微点一下PPT）

> So in practice / attention is limited by **memory bandwidth**, / not computation. //

---

# 🟦 Slide 21（25s）

> Now let’s see / how this changes in AttAcc. //

👉（手往左右比）

> In traditional execution / data moves between **DRAM and GPU**. //

> Especially KV matrices / which cross the memory interface repeatedly. //

> This creates a serious **bandwidth bottleneck**. //

👉（语气稍微强调）

> AttAcc solves this / by executing attention **inside memory**. //

> So the data path becomes shorter / and data movement is reduced. //

---

# 🟦 Slide 22（35s）⭐重点

> To enable this / we look at attention at the **operator level**. //

👉（指公式/表格）

> Attention can be decomposed into three steps:
> **score**, **softmax**, and **context**. //

（这里可以手点三下）

> These are mapped to PIM hardware:
> GEMV runs in **DRAM banks**,
> and softmax runs in the **buffer die**. //

> Importantly / KV matrices always **stay in DRAM**. //

👉（轻停顿，给理解时间）

> So attention is transformed into **GEMV + softmax**,
> which fits naturally into PIM execution. //

---

# 🟦 Slide 23（40s）🔥核心页（一定要指图）

👉（指图左 → 中 → 右）

> This figure shows / how attention is executed **inside memory**. //

👉（指左边）

> First / the query **Q enters memory**. //

👉（指中间）

> Then computation follows a simple pipeline:
> **score → softmax → context**. //

👉（指右边）

> Meanwhile / **K and V remain in DRAM** throughout the process. //

👉（画一个“留在里面”的手势）

> The computation is **partitioned across memory banks** / and parallel units. //

👉（语气稍微收紧）

> So we avoid moving large KV data /
> which significantly improves efficiency. //

---

# 🟦 Slide 24（30s）

> Finally / why is attention particularly suitable for PIM? //

> Because it has three key properties:
> it is dominated by **GEMV**,
> has **low arithmetic intensity**,
> and is **memory-bound**. //

👉（停一下）

> These match well with **DRAM-level parallelism**. //

> So attention can be naturally mapped to PIM /
> for more efficient execution. //

---

# 🧾 收尾（10s，必须稳）

👉（看观众，不看PPT）

> In summary //
> attention is **memory-bound**,
> and mapping its operations into memory /
