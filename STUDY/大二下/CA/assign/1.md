## 🟦 Slide 1 — Why Attention is Memory-Bound

> First, let’s look at why attention is the bottleneck.

In autoregressive inference, attention is dominated by **GEMV operations rather than GEMM**,  
which means the arithmetic intensity is very low.

At the same time, we need to repeatedly access large **KV matrices** during decoding.

So in practice, attention is not limited by compute,  
but by **memory bandwidth and data movement**.

---

## 🟦 Slide 2 — Traditional vs AttAcc

> Now, let’s see how this changes in AttAcc.

In the traditional approach,  
data is moved back and forth between DRAM and GPU.

This means large KV matrices repeatedly cross the memory interface,  
which creates a serious bandwidth bottleneck.

In contrast, AttAcc **reorganizes attention execution** so that computation happens inside memory.

This significantly reduces off-chip data movement,  
especially for KV matrices, which dominate memory traffic.

---

## 🟦 Slide 3 — Mapping Attention to PIM Hardware（核心）

> To understand this, we need to look at attention at the operator level.

Attention can be decomposed into three steps:

- First, compute the score using (Q \times K^T)
    
- Then apply softmax
    
- And finally compute the context using the value matrix
    

In AttAcc, these operations are directly mapped to PIM hardware:

- GEMV operations are executed inside **DRAM banks**
    
- Softmax is handled in the **buffer die**
    
- And importantly, the KV matrices always remain in DRAM
    

So essentially, attention is decomposed into **GEMV and Softmax**,  
which can be directly mapped to DRAM-level compute units.

---

## 🟦 Slide 4 — Attention Dataflow in PIM

> Now let’s look at the dataflow.

The key idea is very simple:

- The query (Q) is sent into memory
    
- The key and value matrices stay inside DRAM
    

Then all computations—score, softmax, and context—  
are executed within the memory system.

Only the final output is sent back.

So compared to the traditional approach,  
the expensive movement of KV data is completely eliminated.

---

## 🟦 Slide 5 — Why Attention Benefits from PIM

> Finally, why does this work particularly well for attention?

Because attention has three key characteristics:

- It is dominated by GEMV
    
- It has low arithmetic intensity
    
- And KV matrices dominate memory traffic
    

These properties make it a perfect match for PIM:

- GEMV maps naturally to **bank-level parallelism**
    
- Softmax can be handled in the buffer die
    
- And KV data can stay in DRAM throughout execution
    

So overall, attention’s structure allows it to be directly mapped onto DRAM-level computation.

---

## 🧾 收尾（一定要说这句）

> In summary, attention is memory-bound,  
> and by mapping its GEMV and Softmax operations into memory,  
> AttAcc eliminates data movement and significantly improves efficiency.
