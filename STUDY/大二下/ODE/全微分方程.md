## 一、什么是全微分方程？

### 1. 从"全微分"说起

你学高数的时候见过二元函数 $u(x,y)$ 的全微分：

$$du = \frac{\partial u}{\partial x}dx + \frac{\partial u}{\partial y}dy$$

现在反过来想：如果有人给你一个方程

$$M(x,y),dx + N(x,y),dy = 0$$

而恰好存在某个函数 $u(x,y)$，使得 $\frac{\partial u}{\partial x} = M$，$\frac{\partial u}{\partial y} = N$，那这个方程其实就是在说

$$du = 0 \quad\Longrightarrow\quad u(x,y) = C$$

**一步就写出通解了。** 这种方程就叫**全微分方程**（也叫恰当方程）。

### 2. 怎么判断是不是全微分方程？

不是随便一个 $M,dx + N,dy = 0$ 都能找到这样的 $u$。判定条件很简单：

> **定理：** 在单连通区域内，$M,N$ 有连续一阶偏导数时，方程是全微分方程的**充要条件**是： $$\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}$$

为什么？因为如果 $u$ 存在，那 $M = u_x$，$N = u_y$，于是 $M_y = u_{xy}$，$N_x = u_{yx}$。二阶混合偏导相等，所以 $M_y = N_x$。

**记忆口诀：** "交叉偏导相等"——$M$ 对 $y$ 求偏导 = $N$ 对 $x$ 求偏导。

---

## 二、确认是全微分方程后，怎么求 $u(x,y)$？

有两种常用方法。

### 方法一：先对一个变量积分，再用另一个条件定剩余项

**步骤：**

**(1)** 由 $u_x = M$，对 $x$ 积分（把 $y$ 当常数）：

$$u = \int M(x,y),dx + \varphi(y)$$

这里 $\varphi(y)$ 是"积分常数"，只不过因为 $y$ 被当常数，所以常数可能含 $y$。

**(2)** 再用 $u_y = N$ 来确定 $\varphi(y)$：

$$\frac{\partial}{\partial y}\left[\int Mdx\right] + \varphi'(y) = N$$

解出 $\varphi'(y)$，积分得 $\varphi(y)$。

**(3)** 通解就是 $u(x,y) = C$。

### 方法二：沿折线路径积分

选一个基点 $(x_0, y_0)$，先沿 $x$ 走再沿 $y$ 走：

$$u(x,y) = \int_{x_0}^{x} M(\xi,y_0)d\xi + \int_{y_0}^{y} N(x, \eta)d\eta$$

两种方法结果一样，选哪个看哪个算起来方便。

### 具体例子

求解 $\left(\cos x + \dfrac{1}{y}\right)dx + \left(\dfrac{1}{y} - \dfrac{x}{y^2}\right)dy = 0$

**第一步：验证**

$$M = \cos x + \frac{1}{y},\quad N = \frac{1}{y} - \frac{x}{y^2}$$

$$M_y = -\frac{1}{y^2},\quad N_x = -\frac{1}{y^2} \quad\checkmark$$

**第二步：求 $u$（用方法一）**

由 $u_x = M$：

$$u = \int\left(\cos x + \frac{1}{y}\right)dx = \sin x + \frac{x}{y} + \varphi(y)$$

由 $u_y = N$：

$$-\frac{x}{y^2} + \varphi'(y) = \frac{1}{y} - \frac{x}{y^2}$$

$$\varphi'(y) = \frac{1}{y} \quad\Longrightarrow\quad \varphi(y) = \ln|y|$$

**通解：** $\sin x + \dfrac{x}{y} + \ln|y| = C$

## 三、凑微分技巧

实际做题时，有些全微分方程不用走上面的正规流程，直接"看出来"就行。这靠的是**记住一些常见的微分恒等式**：

$$y,dx + x,dy = d(xy)$$

$$\frac{y,dx - x,dy}{y^2} = d!\left(\frac{x}{y}\right)$$

$$\frac{x,dy - y,dx}{x^2} = d!\left(\frac{y}{x}\right)$$

$$\frac{x,dy - y,dx}{x^2 + y^2} = d!\left(\arctan\frac{y}{x}\right)$$

$$\frac{x,dx + y,dy}{\sqrt{x^2+y^2}} = d!\left(\sqrt{x^2+y^2}\right)$$

你之前做过的第21题就是用这个技巧秒杀的。遇到方程时，先扫一眼能不能凑出这些形式，能凑就直接写答案。

## 四、积分因子——当方程"不恰当"时的救命工具

### 1. 问题的提出

如果验证发现 $M_y \neq N_x$，方程不是全微分方程。怎么办？

**核心思路：** 找一个非零函数 $\mu(x,y)$，乘上去之后让它变成全微分方程：

$$\mu Mdx + \mu Ndy = 0 \quad\text{是全微分}$$

这个 $\mu$ 就叫**积分因子**。

### 2. 积分因子满足什么条件？

要求 $(\mu M)_y = (\mu N)_x$，展开：

$$M\mu_y + \mu M_y = N\mu_x + \mu N_x$$

这是一个关于 $\mu$ 的偏微分方程，一般很难解。所以我们通常**假设 $\mu$ 只依赖一个变量**。

### 3. 只依赖于 $x$ 的积分因子

如果 $\mu = \mu(x)$，则 $\mu_y = 0$，上面的条件变成：

$$\mu M_y = N\mu' + \mu N_x$$

$$\frac{\mu'}{\mu} = \frac{M_y - N_x}{N}$$

**关键判断：** 如果 $\dfrac{M_y - N_x}{N}$ 算出来**只含 $x$**（不含 $y$），记它为 $\varphi(x)$，那么：

$$\mu(x) = e^{\int \varphi(x),dx}$$

### 4. 只依赖于 $y$ 的积分因子

对称地，如果 $\dfrac{N_x - M_y}{M}$ 算出来**只含 $y$**，记它为 $\psi(y)$，那么：

$$\mu(y) = e^{\int \psi(y),dy}$$

**注意分子的符号相反！** 记忆方法：

- 依赖 $x$ → 分母是 $N$ → 分子是 $M_y - N_x$
- 依赖 $y$ → 分母是 $M$ → 分子是 $N_x - M_y$

### 5. 完整做题流程

$$\boxed{M,dx + N,dy = 0}$$

$$\downarrow$$

$$\text{算 } M_y \text{ 和 } N_x$$

$$\downarrow$$

$$M_y = N_x? \xrightarrow{\text{是}} \text{全微分，直接求 } u$$

$$\downarrow \text{不是}$$

$$\text{算 } \frac{M_y - N_x}{N}，\text{只含 } x? \xrightarrow{\text{是}} \mu = e^{\int \frac{M_y-N_x}{N}dx}$$

$$\downarrow \text{不是}$$

$$\text{算 } \frac{N_x - M_y}{M}，\text{只含 } y? \xrightarrow{\text{是}} \mu = e^{\int \frac{N_x-M_y}{M}dy}$$

### 6. 具体例子

求解 $\left(3y + \dfrac{y^2}{x}\right)dx + (x+y),dy = 0$

**第一步：**

$$M_y = 3 + \frac{2y}{x},\quad N_x = 1,\quad M_y \neq N_x$$

**第二步：** 试 $\dfrac{M_y - N_x}{N}$：

$$\frac{3 + 2y/x - 1}{x + y} = \frac{2 + 2y/x}{x+y} = \frac{2(x+y)/x}{x+y} = \frac{2}{x}$$

只含 $x$！所以：

$$\mu = e^{\int \frac{2}{x}dx} = x^2$$

**第三步：** 乘以 $x^2$：

$$(3x^2y + xy^2),dx + (x^3 + x^2y),dy = 0$$

验证：$(3x^2y+xy^2)_y = 3x^2 + 2xy$，$(x^3+x^2y)_x = 3x^2 + 2xy$ ✓

**第四步：** 求 $u$：

$$u = \int(x^3 + x^2y),dy = x^3y + \frac{1}{2}x^2y^2 + g(x)$$

$$u_x = 3x^2y + xy^2 + g'(x) = 3x^2y + xy^2 \implies g'(x) = 0$$

**通解：** $x^3y + \dfrac{1}{2}x^2y^2 = C$

## 五、齐次函数的积分因子（补充公式）

讲义里还提到一个特殊情形：

> 如果 $M, N$ 都是 $x, y$ 的 **$m$ 次齐次函数**（即 $M(tx,ty) = t^m M(x,y)$），且 $xM + yN \neq 0$，则 $$\mu = \frac{1}{xM + yN}$$ 是一个积分因子。

这个公式的证明用到了 Euler 齐次函数定理（$x\frac{\partial f}{\partial x} + y\frac{\partial f}{\partial y} = mf$），考试可能会考证明题（你讲义里的考题8就是这道）。

---

## 总结

今天学了三件事：

**① 全微分方程：** 判断 $M_y = N_x$，然后求势函数 $u(x,y) = C$。两种求法：先积后补，或折线积分。

**② 凑微分：** 记住常见恒等式，遇到能凑的直接秒杀。

**③ 积分因子：** 不是全微分时，算 $\frac{M_y - N_x}{N}$ 或 $\frac{N_x - M_y}{M}$，看哪个只含一个变量，就能找到 $\mu$。乘上之后变回全微分方程，再用①的方法解。

## 第16题

$xy' = x\cos x - 2\sin x - 2y$，$y(\pi) = 0$

改写：$y' + \dfrac{2}{x}y = \cos x - \dfrac{2\sin x}{x}$

积分因子 $\mu = e^{\int \frac{2}{x}dx} = x^2$

$$d(x^2 y) = x^2\cos x - 2x\sin x$$

注意 $(x^2\sin x)' = x^2\cos x + 2x\sin x$，所以：

$$x^2\cos x - 2x\sin x = (x^2\sin x)' - 4x\sin x$$

换个思路，直接积分右边：

$$\int (x^2\cos x - 2x\sin x),dx$$

注意 $\frac{d}{dx}(x^2\sin x) = 2x\sin x + x^2\cos x$，所以 $x^2\cos x = \frac{d}{dx}(x^2\sin x) - 2x\sin x$。

$$\int(x^2\cos x - 2x\sin x)dx = \int\frac{d}{dx}(x^2\sin x)dx - 4\int x\sin x,dx$$

$$= x^2\sin x - 4(-x\cos x + \sin x) + C = x^2\sin x + 4x\cos x - 4\sin x + C$$

所以：

$$x^2 y = x^2\sin x + 4x\cos x - 4\sin x + C$$

代入 $y(\pi)=0$：

$$0 = \pi^2\sin\pi + 4\pi\cos\pi - 4\sin\pi + C = -4\pi + C$$

$$C = 4\pi$$

$$\boxed{y = \sin x + \frac{4\cos x}{x} - \frac{4\sin x}{x^2} + \frac{4\pi}{x^2}}$$

## 第17题

$\dfrac{dy}{dx} - \dfrac{xy}{2(x^2-1)} - \dfrac{x}{2y} = 0$，$y(0)=1$

改写：$\dfrac{dy}{dx} = \dfrac{xy}{2(x^2-1)} + \dfrac{x}{2y}$

这是伯努利型。两边乘 $2y$：

$$2y\frac{dy}{dx} = \frac{xy^2}{x^2-1} + x$$

令 $z = y^2$，则 $z' = 2yy'$：

$$z' - \frac{x}{x^2-1}z = x$$

积分因子 $\mu = e^{-\int \frac{x}{x^2-1}dx} = e^{-\frac{1}{2}\ln|x^2-1|} = \frac{1}{\sqrt{|x^2-1|}}$

在 $x=0$ 附近，$|x|<1$，$x^2-1<0$，所以 $\mu = \frac{1}{\sqrt{1-x^2}}$。

$$\frac{d}{dx}\left(\frac{z}{\sqrt{1-x^2}}\right) = \frac{x}{\sqrt{1-x^2}}$$

$$\frac{z}{\sqrt{1-x^2}} = -\sqrt{1-x^2} + C$$

$$z = -(1-x^2) + C\sqrt{1-x^2}$$

即 $y^2 = x^2 - 1 + C\sqrt{1-x^2}$

代入 $y(0)=1$：$1 = -1 + C$，故 $C = 2$。

$$\boxed{y^2 = x^2 - 1 + 2\sqrt{1-x^2}}$$

$$\boxed{x^5 y + \frac{x^4}{4} = C}$$

## 第21题

$\dfrac{x,dx + y,dy}{\sqrt{1+x^2+y^2}} + \dfrac{y,dx - x,dy}{x^2+y^2} = 0$

注意 $x,dx + y,dy = \frac{1}{2}d(x^2+y^2) = d(\sqrt{1+x^2+y^2})\cdot\sqrt{1+x^2+y^2}$

所以第一项 $= \dfrac{d(\sqrt{1+x^2+y^2})\cdot\sqrt{1+x^2+y^2}}{\sqrt{1+x^2+y^2}} = d\left(\sqrt{1+x^2+y^2}\right)$

第二项：$\dfrac{y,dx - x,dy}{x^2+y^2} = -d\left(\arctan\dfrac{y}{x}\right)$

（因为 $d\left(\arctan\frac{y}{x}\right) = \frac{x,dy - y,dx}{x^2+y^2}$）

所以方程化为：

$$d\left(\sqrt{1+x^2+y^2}\right) - d\left(\arctan\frac{y}{x}\right) = 0$$

$$\boxed{\sqrt{1+x^2+y^2} - \arctan\frac{y}{x} = C}$$
$$\boxed{\sqrt{1+x^2+y^2} + \arctan\frac{x}{y} = C}$$

## 第24题

$(4y,dx + x,dy) - x^2,dx = 0$

即 $M = 4y - x^2$，$N = x$。

$\frac{\partial M}{\partial y} = 4$，$\frac{\partial N}{\partial x} = 1$，不是全微分。

尝试积分因子 $\mu = x^n$：

需要 $\frac{\partial(\mu M)}{\partial y} = \frac{\partial(\mu N)}{\partial x}$

$$4x^n = (n+1)x^n$$

故 $n = 3$，积分因子 $\mu = x^3$。

乘以 $x^3$：

$(4x^3 y - x^5)dx + x^4,dy = 0$

验证：$\frac{\partial}{\partial y}(4x^3y - x^5) = 4x^3$，$\frac{\partial}{\partial x}(x^4) = 4x^3$ ✓

求 $F$：

$$F = \int x^4,dy = x^4 y + g(x)$$

$$\frac{\partial F}{\partial x} = 4x^3 y + g'(x) = 4x^3 y - x^5$$

$$g'(x) = -x^5 \Rightarrow g(x) = -\frac{x^6}{6}$$

$$\boxed{x^4 y - \frac{x^6}{6} = C}$$

## 第26题

$(y,dx - x,dy) + x^4,dx = 0$

即 $M = y + x^4$，$N = -x$。

$\frac{\partial M}{\partial y} = 1$，$\frac{\partial N}{\partial x} = -1$，不全微分。

注意 $y,dx - x,dy = -x^2,d\left(\frac{y}{x}\right)$，尝试积分因子 $\mu = \frac{1}{x^2}$：

$$\frac{y,dx - x,dy}{x^2} + x^2,dx = 0$$

$$-d\left(\frac{y}{x}\right) + x^2,dx = 0$$

积分：

$$-\frac{y}{x} + \frac{x^3}{3} = C$$

$$\boxed{\frac{x^3}{3} - \frac{y}{x} = C}$$

## 第28题

$2,dx + (2x - 3y - 3),dy = 0$，$y(2) = 0$

$M = 2$，$N = 2x - 3y - 3$。

$\frac{\partial M}{\partial y} = 0$，$\frac{\partial N}{\partial x} = 2$，不全微分。

$\frac{\frac{\partial N}{\partial x} - \frac{\partial M}{\partial y}}{M} = \frac{2}{2} = 1$，仅与 $y$ 有关（常数），所以积分因子 $\mu = e^{\int 1,dy} = e^y$。

乘以 $e^y$：

$$2e^y,dx + (2x - 3y - 3)e^y,dy = 0$$

验证：$\frac{\partial}{\partial y}(2e^y) = 2e^y$，$\frac{\partial}{\partial x}((2x-3y-3)e^y) = 2e^y$ ✓

求 $F$：

$$F = \int 2e^y,dx = 2xe^y + g(y)$$

$$\frac{\partial F}{\partial y} = 2xe^y + g'(y) = (2x-3y-3)e^y$$

$$g'(y) = -(3y+3)e^y$$

$$g(y) = -\int(3y+3)e^y,dy = -(3y+3)e^y + 3e^y + C_0 = -3ye^y + C_0$$

所以 $F = 2xe^y - 3ye^y = C$，即：

$$(2x - 3y)e^y = C$$

代入 $y(2)=0$：$(4-0)\cdot 1 = C$，$C = 4$。

$$\boxed{(2x-3y)e^y = 4}$$

## 第42题

设 $f(x)$ 连续，且 $f(x) + 2\displaystyle\int_0^x f(t),dt = x^2$，求 $f(x)$。

两边对 $x$ 求导：

$$f'(x) + 2f(x) = 2x$$

这是一阶线性方程，积分因子 $\mu = e^{2x}$：

$$d(e^{2x}f) = 2xe^{2x},dx$$

$$e^{2x}f = \int 2xe^{2x},dx = xe^{2x} - \frac{1}{2}e^{2x} + C$$

$$f(x) = x - \frac{1}{2} + Ce^{-2x}$$

由原方程令 $x=0$：$f(0) = 0$，所以 $0 = -\frac{1}{2} + C$，$C = \frac{1}{2}$。

$$\boxed{f(x) = x - \frac{1}{2} + \frac{1}{2}e^{-2x}}$$

## 第44题

设 $\varphi(x)$ 有一阶连续导数，$\varphi(0)=1$，且 $(y^2+xy),dx + (\varphi(x)+2xy),dy = 0$ 是全微分方程。求 $\varphi(x)$ 及通积分。

**全微分条件：** $\dfrac{\partial M}{\partial y} = \dfrac{\partial N}{\partial x}$

$M = y^2 + xy$，$N = \varphi(x) + 2xy$

$$\frac{\partial M}{\partial y} = 2y + x, \quad \frac{\partial N}{\partial x} = \varphi'(x) + 2y$$

令 $2y + x = \varphi'(x) + 2y$，得 $\varphi'(x) = x$。

$$\varphi(x) = \frac{x^2}{2} + C_0$$

由 $\varphi(0)=1$：$C_0 = 1$，故 $\boxed{\varphi(x) = \frac{x^2}{2} + 1}$。

**求通积分：** 方程变为 $(y^2+xy)dx + (\frac{x^2}{2}+1+2xy)dy = 0$

$$F = \int N,dy = \left(\frac{x^2}{2}+1\right)y + xy^2 + g(x)$$

$$\frac{\partial F}{\partial x} = xy + y^2 + g'(x) = y^2 + xy$$

所以 $g'(x) = 0$，$g(x) = 0$。

$$\boxed{\frac{x^2 y}{2} + y + xy^2 = C}$$
