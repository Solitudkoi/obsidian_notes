Universal Travel Sites
After finishing her tour around the Earth, CYLL is now planning a universal travel sites development project. After a careful investigation, she has a list of capacities of all the **satellite transportation stations** in hand. To estimate a budget, she must know the minimum capacity that a **planet station** must have to guarantee that every space vessel can dock and download its passengers on arrival.
在完成绕地球之旅后，CYLL 现在正计划一个宇宙旅游景点开发项目。经过仔细调查，她手头有一份所有*卫星运输站*运力的清单。为了估算预算，她必须知道行星站必须具备的最小运力，以确保每艘太空船都能在抵达时停靠并让乘客下船。
### Input Specification:

Each input file contains one test case. For each case, the first line contains the names of the source and the destination **planets**, and a positive integer `N` (≤500). Then `N` lines follow, each in the format: `source[i] destination[i] capacity[i]` where `source[i]` and `destination[i]` are the names of the satellites and the two involved planets, and `capacity[i]` > 0 is the maximum number of passengers that can be transported at one pass from `source[i]` to `destination[i]`. Each name is a string of 3 uppercase characters chosen from {A-Z}, e.g., ZJU.

Note that the satellite transportation stations have no accommodation facilities for the passengers. Therefore none of the passengers can stay. Such a station will not allow arrivals of space vessels that contain more than its own capacity. It is guaranteed that the list contains neither the routes to the source planet nor that from the destination planet.
每个输入文件包含一个测试用例。对于每个用例，第一行包含源行星和目标行星的名称，以及一个正整数N（500）。然后是N行，每行的格式为：source[i] destination[i] capacity[i]，其中source[i]和destination[i]是卫星以及所涉及的两个行星的名称，capacity[i] > 0是从source[i]到destination[i]一次能运送的最大乘客数量。每个名称是一个由3个大写字母组成的字符串，这些字母取自{A - Z}，例如ZJU。
请注意，卫星运输站没有为乘客提供住宿设施。因此，没有乘客可以停留。这样的站点不允许搭载超过其自身容量的太空船抵达。保证列表中既不包含通往源行星的路线，也不包含从目标行星出发的路线。

7-2 Uniqueness of MST

Given any weighted undirected graph, there exists at least one minimum spanning tree (MST) if the graph is connected. Sometimes the MST may not be unique though. Here you are supposed to calculate the minimum total weight of the MST, and also tell if it is unique or not.
给定任意一个**带权无向图**，如果该图是**连通**的，那么至少存在一棵**最小生成树（MST）**。不过，有时候最小生成树可能不是唯一的。在这里，你需要计算最小生成树的**最小总权值**，并且还要判断它是否唯一。
### Input Specification:

Each input file contains one test case. Each case starts with a line containing 2 numbers N (≤ 500), and M, which are the total number of vertices, and the number of edges, respectively. Then M lines follow, each describes an edge by 3 integers:
每个输入文件包含一个测试用例。每个用例的第一行包含两个数字 N（≤ 500）和 M，分别表示顶点的总数和边的数量。接下来有 M 行，每行用 3 个整数描述一条边：

```
V1 V2 Weight
```

where `V1` and `V2` are the two ends of the edge (the vertices are numbered from 1 to N), and `Weight` is the positive weight on that edge. It is guaranteed that the total weight of the graph will not exceed 230.
其中 `V1` 和 `V2` 是这条边的两个端点（顶点编号从 1 到 N），`权值` 是这条边上的正权值。保证图的总权值不会超过 2³⁰。

### Output Specification:

For each test case, first print in a line the total weight of the minimum spanning tree if there exists one, or else print `No MST` instead. Then if the MST exists, print in the next line `Yes` if the tree is unique, or `No` otherwise. There there is no MST, print the number of connected components instead.
对于每个测试用例，如果存在最小生成树，首先在一行中输出最小生成树的总权值；否则输出 `No MST`。然后，如果最小生成树存在，若该树是唯一的，则在下一行输出 `Yes`，否则输出 `No`。如果不存在最小生成树，则输出**连通分量的数量**。

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#define MAXVERTICES 500
#define INF 1000000000
// 邻接表节点
struct Node {
    int vertex;
    int capacity;
    struct Node* next;
};
// 图结构
struct Graph {
    int numVertices;
    struct Node** adjList;
};
// 创建图
struct Graph* createGraph(int numVertices) {
    struct Graph* graph = (Graph*)malloc(sizeof(Graph));
    graph->numVertices = numVertices;
    graph->adjList = (struct Node**)malloc(numVertices * sizeof(struct Node*));
    for (int i = 0; i < numVertices; i++) {
        graph->adjList[i] = NULL;
    }
    return graph;
}

// 添加边
void addEdge(structGraph* graph, int src, int dest, int capacity) {
    struct Node* newNode = (struct Node*)malloc(sizeof(struct Node));
    newNode->vertex = dest;
    newNode->capacity = capacity;
    newNode->next = graph->adjList[src];
    graph->adjList[src] = newNode;

    // 反向边
    newNode = (struct Node*)malloc(sizeof(struct Node));
    newNode->vertex = src;
    newNode->capacity = 0;
    newNode->next = graph->adjList[dest];
    graph->adjList[dest] = newNode;
}

// BFS寻找增广路径
int bfs(struct Graph* graph, int s, int t, int parent[]) {
    int visited[MAX_VERTICES];
    memset(visited, 0, sizeof(visited));

    int queue[MAX_VERTICES];
    int front = 0, rear = 0;

    queue[rear++] = s;
    visited[s] = 1;
    parent[s] = -1;

    while (front < rear) {
        int u = queue[front++];

        Node* temp = graph->adjList[u];
        while (temp != NULL) {
            int v = temp->vertex;
            if (!visited[v] && temp->capacity > 0) {
                queue[rear++] = v;
                parent[v] = u;
                visited[v] = 1;
            }
            temp = temp->next;
        }
    }

    return visited[t];
}

// Edmonds-Karp算法计算最大流
int edmondsKarp(Graph* graph, int s, int t) {
    int parent[MAX_VERTICES];
    int maxFlow = 0;

    while (bfs(graph, s, t, parent)) {
        int pathFlow = INF;
        for (int v = t; v != s; v = parent[v]) {
            int u = parent[v];
            Node* temp = graph->adjList[u];
            while (temp->vertex != v) {
                temp = temp->next;
            }
            pathFlow = (pathFlow < temp->capacity) ? pathFlow : temp->capacity;
        }

        for (int v = t; v != s; v = parent[v]) {
            int u = parent[v];
            Node* temp = graph->adjList[u];
            while (temp->vertex != v) {
                temp = temp->next;
            }
            temp->capacity -= pathFlow;

            temp = graph->adjList[v];
            while (temp->vertex != u) {
                temp = temp->next;
            }
            temp->capacity += pathFlow;
        }

        maxFlow += pathFlow;
    }

    return maxFlow;
}

// 字符串到索引的映射
int stringToIndex(char* str, int indexMap[], int* indexCount) {
    for (int i = 0; i < *indexCount; i++) {
        if (strcmp(str, (char*)&indexMap[i * 3]) == 0) {
            return i;
        }
    }
    memcpy((char*)&indexMap[(*indexCount) * 3], str, 3);
    return (*indexCount)++;
}

int main() {
    char source[4], destination[4];
    int n;
    scanf("%s %s %d", source, destination, &n);

    int indexMap[MAX_VERTICES * 3];
    int indexCount = 0;

    int s = stringToIndex(source, indexMap, &indexCount);
    int t = stringToIndex(destination, indexMap, &indexCount);

    Graph* graph = createGraph(indexCount);

    for (int i = 0; i < n; i++) {
        char src[4], dest[4];
        int capacity;
        scanf("%s %s %d", src, dest, &capacity);

        int u = stringToIndex(src, indexMap, &indexCount);
        int v = stringToIndex(dest, indexMap, &indexCount);

        addEdge(graph, u, v, capacity);
    }

    int maxFlow = edmondsKarp(graph, s, t);
    printf("%d\n", maxFlow);

    // 释放内存
    for (int i = 0; i < graph->numVertices; i++) {
        Node* temp = graph->adjList[i];
        while (temp != NULL) {
            Node* next = temp->next;
            free(temp);
            temp = next;
        }
    }
    free(graph->adjList);
    free(graph);

    return 0;
}
