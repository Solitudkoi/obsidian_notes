# Strongly Connected Components

### Format of functions:

```c++
void StronglyConnectedComponents( Graph G, void (*visit)(Vertex V) );
```

where `Graph` is defined as the following:

```c++
typedef struct VNode *PtrToVNode;
```

在图论中，一个**强连通分量**（SCC）是有向图的一个子图，在这个子图内，任意一个顶点都可以到达其他所有顶点。以下是详细内容：

### 定义

- 在有向图G中，如果对于两个顶点\(v_i\)和\(v_j\)（\(v_i\neq v_j\)），存在从\(v_i\)到\(v_j\)的有向路径，同时也存在从\(v_j\)到\(v_i\)的有向路径，那么这两个顶点就被称为是强连通的。
- 如果有向图G中的每一对顶点都是强连通的，那么G就被称为强连通图。有向图的极大强连通子图被称为强连通分量。

### 示例

- 例如，在一个具有顶点1、2、3、4、5、6、7的图中，子图\(\{1, 2, 3, 4\}\)和\(\{5, 6, 7\}\)可以是强连通分量。因为在\(\{1, 2, 3, 4\}\)中，每个顶点都能到达其他所有顶点，\(\{5, 6, 7\}\)的情况也是如此。

### 寻找强连通分量的算法

- **科萨拉尤算法（Kosaraju's algorithm）**：该算法使用两次深度优先搜索。首先，对原始图进行深度优先搜索，记录每个节点的离开时间。然后，选择离开时间最晚的顶点，并对转置图（所有边方向反转的图）进行深度优先搜索。能够被遍历到的顶点构成一个强连通分量。重复这个过程，直到处理完所有顶点。
- **塔扬算法（Tarjan's algorithm）**：它基于对图的深度优先搜索。每个强连通分量都是搜索树中的一棵子树。在搜索过程中，维护两个数组，dfn（记录节点的搜索序号）和low（记录该节点或其子树能够追溯到的栈中节点的最早序号）。当对于一个节点u，\(dfn(u)=low(u)\)时，就表明以u为根的子树是一个强连通分量。

### 性质

- 任何有向图的强连通分量都构成了对该图的一个划分，将其划分为若干个本身是强连通的子图。
- 如果将每个强连通分量收缩为一个单个顶点，得到的图是一个有向无环图，被称为原始图的凝聚图。

### 应用

- **网络分析**：在社交网络分析中，强连通分量可以帮助识别出彼此之间联系紧密的人群群体。
- **环检测**：用于检测有向图中的环。如果检测到一个强连通分量，那么可以确定图中至少存在一个环。
- **软件工程**：可以帮助识别软件系统中高度相互依赖的模块或组件，这些模块或组件在维护或重构时可能需要特别关注。

```
void StronglyConnectedComponents(Graph G, void (*visit)(Vertex V)) 
{
    int numVertices = G->NumOfVertices;
    int disc[MaxVertices];    // 发现时间戳
    int low[MaxVertices];     // 能回溯到的最早时间戳
    bool onStack[MaxVertices];// 是否在栈中
    int stack[MaxVertices];   // 顶点栈
    int top = -1;             // 栈顶指针
    int time = 0;             // 时间计数器
    int dfsStack[MaxVertices];// DFS 调用栈
    int dfsTop = -1;          // DFS 栈顶指针
    PtrToVNode adjPtr[MaxVertices]; // 邻接表指针
    
    // 初始化所有数组
    for (Vertex v = 0; v < numVertices; v++) {
        disc[v] = -1;
        low[v] = -1;
        onStack[v] = false;
    }
    
    // 对每个未访问的顶点启动 DFS
    for (Vertex v = 0; v < numVertices; v++) {
        if (disc[v] == -1) {
            // 初始化 DFS 栈
            dfsStack[++dfsTop] = v;
            disc[v] = low[v] = time++;
            stack[++top] = v;
            onStack[v] = true;
            adjPtr[v] = G->Array[v]; // 保存邻接表指针
            
            while (dfsTop >= 0) {
                Vertex current = dfsStack[dfsTop];
                PtrToVNode adj = adjPtr[current];
                
                // 处理当前顶点的下一个邻接顶点
                if (adj != NULL) {
                    Vertex neighbor = adj->Vert;
                    adjPtr[current] = adj->Next; // 移动到下一个邻接顶点
                    
                    if (disc[neighbor] == -1) {
                        // 未访问的顶点，压入 DFS 栈
                        disc[neighbor] = low[neighbor] = time++;
                        stack[++top] = neighbor;
                        onStack[neighbor] = true;
                        dfsStack[++dfsTop] = neighbor;
                        adjPtr[neighbor] = G->Array[neighbor];
                    } else if (onStack[neighbor]) {
                        // 已访问且在栈中的顶点，更新 low
                        low[current] = (low[current] < disc[neighbor]) ? low[current] : disc[neighbor];
                    }
                } else {
                    // 当前顶点的所有邻接顶点都已处理
                    // 检查是否为 SCC 的根
                    if (disc[current] == low[current]) {
                        Vertex u;
                        do {
                            u = stack[top--];
                            onStack[u] = false;
                            visit(u);
                        } while (u != current);
                        printf("\n"); // 每个 SCC 后换行
                    }
                    
                    // 回溯
                    if (dfsTop > 0) {
                        Vertex parent = dfsStack[dfsTop-1];
                        low[parent] = (low[parent] < low[current]) ? low[parent] : low[current];
                    }
                    dfsTop--;
                }
            }
        }
    }
}
```

```
void StronglyConnectedComponents(Graph G, void (*visit)(Vertex)) {
    int Index = 0;
    int dfn[MaxVertices] = {0};
    int low[MaxVertices] = {0};
    bool inStack[MaxVertices] = {false};
    Vertex stack[MaxVertices];
    int top = -1;

    void Tarjan(Vertex v) {
        dfn[v] = low[v] = ++Index;
        stack[++top] = v;
        inStack[v] = true;

        for (PtrToVNode p = G->Array[v]; p; p = p->Next) {
            Vertex w = p->Vert;
            if (!dfn[w]) {
                Tarjan(w);
                if (low[w] < low[v])
                    low[v] = low[w];
            } else if (inStack[w]) {
                if (dfn[w] < low[v])
                    low[v] = dfn[w];
            }
        }

        if (low[v] == dfn[v]) {
            Vertex w;
            do {
                w = stack[top--];
                inStack[w] = false;
                visit(w);
            } while (w != v);
            printf("\n");
        }
    }

    for (int i = 0; i < G->NumOfVertices; i++) {
        if (!dfn[i])
            Tarjan(i);
    }
}
```
