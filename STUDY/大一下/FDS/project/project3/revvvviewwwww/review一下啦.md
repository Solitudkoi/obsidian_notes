邻接表（Adjacency List）和优先队列（Priority Queue）是计算机科学中常用的数据结构，分别用于图的表示和高效获取极值元素。以下是它们的详细解释：

### **一、邻接表（Adjacency List）**

#### **定义**

邻接表是一种用于表示图（Graph）的链式存储结构，适用于**稀疏图**（边数较少的图）。

  

- 对于图中的每个顶点（Vertex），用一个链表（或动态数组）存储其所有相邻的顶点及对应的边权（若为带权图）。
- 本质是**数组 + 链表**的组合：
    - 数组的每个元素对应一个顶点，存储该顶点的链表头指针。
    - 链表中的每个节点表示与该顶点相邻的顶点及边权。

#### **示例**
```c
typedef struct AdjVNode *PtrToAdjVNode; 
struct AdjVNode{
    Vertex AdjV;
    PtrToAdjVNode Next;
};

typedef struct Vnode{
    PtrToAdjVNode FirstEdge;
} AdjList[MaxVertexNum];

typedef struct GNode *PtrToGNode;
struct GNode{  
    int Nv;
    int Ne;
    AdjList G;
};
typedef PtrToGNode LGraph;
```


（无向图的邻接表：顶点 1 的链表包含顶点 2 和 3，顶点 2 的链表包含顶点 1 和 4，以此类推。）

#### **特点与应用**

- **优点**：
    1. **空间效率高**：仅存储实际存在的边，适合稀疏图（边数 \(E \ll V^2\)，V 为顶点数）。
    2. **增删边灵活**：修改边的关系时只需操作链表，无需遍历整个矩阵。
- **缺点**：
    1. **查询边是否存在较慢**：需遍历目标顶点的链表，时间复杂度为 \(O(\text{出度})\)。
    2. **不适合稠密图**：稠密图（边数接近 \(V^2\)）的邻接表会退化为邻接矩阵的效率，空间浪费可能增加。
- **典型应用**：
    - 图的遍历（如 DFS、BFS）。
    - 最短路径算法（如 Dijkstra 算法、Bellman-Ford 算法）。
    - 最小生成树算法（如 Kruskal 算法的优化）。

### **二、优先队列（Priority Queue）**

#### **定义**

优先队列是一种抽象数据类型（ADT），其每个元素都有一个**优先级**（Priority），队列的操作（如插入、删除）基于优先级而非先进先出（FIFO）。

- **核心操作**：
    1. **插入元素**（Insert）：将元素加入队列。
    2. **获取并删除最高优先级元素**（Extract Max/Min）：根据队列类型返回并移除优先级最高的元素。
- **实现方式**：
    - 常用 ** 堆（Heap）** 实现（如二叉堆、斐波那契堆），时间复杂度为 \(O(\log n)\) 级。
    - 其他实现：有序数组（插入 \(O(n)\)，删除 \(O(1)\)）、平衡二叉搜索树（插入 / 删除 \(O(\log n)\)）。

#### **类型**

- **最大优先队列**：优先级最高的元素先出队（如 “最大堆”）。
- **最小优先队列**：优先级最低的元素先出队（如 “最小堆”）。

#### **示例**

- 最小优先队列（用最小堆实现）： 元素集合 \(\{3, 1, 4, 2\}\)，插入后堆结构为 \(1 \rightarrow 3 \rightarrow 4 \rightarrow 2\)，首次提取的元素为 1。

#### **特点与应用**

- **优点**：
    1. **高效获取极值**：提取最大 / 最小元素的时间复杂度为 \(O(\log n)\)（基于堆实现）。
    2. **动态性强**：支持实时插入和删除元素，保持优先级顺序。
- **缺点**：
    1. **不支持直接访问中间元素**：需通过堆的性质间接操作。
    2. **实现较复杂**：堆的调整需要一定的算法基础。
- **典型应用**：
    - **最短路径算法**：Dijkstra 算法中用优先队列高效获取当前距离最小的顶点。
    - **任务调度**：操作系统中按优先级分配资源（如实时系统中的任务队列）。
    - **数据压缩**：Huffman 编码中构建最优二叉树。
    - **合并有序数组**：如归并 K 个有序数组时，用优先队列维护当前最小值。

### **三、关联与对比**

1. **在图算法中的结合**：
    - Dijkstra 算法中，用**邻接表表示图结构**，用**优先队列（最小堆）高效选取当前最短路径顶点**，将时间复杂度从 \(O(V^2)\)（邻接矩阵 + 暴力搜索）优化至 \(O((V+E)\log V)\)。
2. **对比总结**：
    
    |**特性**|**邻接表**|**优先队列**|
    |---|---|---|
    |**本质**|图的存储结构|基于优先级的队列抽象|
    |**核心操作**|遍历邻接顶点|插入、提取极值元素|
    |**时间复杂度**|遍历邻接边 \(O(E)\)|插入 / 提取 \(O(\log n)\)|
    |**典型场景**|稀疏图的存储与遍历|极值元素的动态管理|
    

  

通过合理组合邻接表和优先队列，可以高效解决许多图论和算法问题（如最短路径、最小生成树等）。
