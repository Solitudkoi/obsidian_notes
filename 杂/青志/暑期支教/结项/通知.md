# 关于组织开展竺可桢学院2025年新时代“使命担当”铸魂工程暑期大学生社会实践活动总结评比工作的通知

发布者：龚梓傲发布时间：2025-08-25浏览次数：99

各位同学：

为深入学习贯彻党的二十届三中全会精神和全国科技“三会”、全国教育大会精神，全面贯彻落实《教育强国建设规划纲要（2024—2035年）》和习近平总书记对浙江大学系列重要指示精神，紧密结合学校高水平“双一流”建设办学使命和发展愿景，深化实践育人和“大思政课”工作成效，鼓励和引导广大青年学生将个人小我融入国家大我，在实践中坚定理想信念、练就过硬本领，在学院党委的高度重视、悉心指导下，竺可桢学院2025年暑期大学生社会实践活动紧扣学校新发展阶段的使命愿景，以“新时代‘使命担当’铸魂工程”为主题，围绕“启真·燎原”“海纳·筑疆”“开物·星火”三个方向展开社会实践活动。600余名竺院学子走进田间地头、高新科技产业、国家重大需求领域，将专业引领融入社会实践，在担当中历练，在实干中成长，深刻感悟“国之大者”的为民情怀，以实际行动践行为民初心。各实践团队开展了形式多样、内容丰富的实践活动，形成了一批主题鲜明、内容丰富、成绩突出、影响广泛的实践项目，涌现出一批优秀的先进集体和个人。

为及时总结工作、交流经验、深化成果，对照《浙江大学大学生社会实践考评说明》，决定对今年活动中表现突出的集体和个人进行评选表彰。现将有关事项通知如下： 

一、评选内容

（一）院级评选

学院将结合各实践队考核答辩与总结材料的情况，评选出院级一等奖、二等级、三等奖与优秀奖。并择优重点推荐参评校级十佳社会实践团队、校级优秀社会实践团队、校级先进个人、校级优秀论文。

（二）校级推荐

1. 校级优秀团队：面向2025年暑期大学生社会实践活动的所有实践团队。要求社会实践主题鲜明，准备充分，内容丰富；取得显著实践成果；与实践地建立了长期的合作关系，有明确的合作项目与服务范围；取得良好的社会效益或经济效益。

2. 校级优秀指导教师：面向担任2025年暑期大学生社会实践团队的指导教师。要求亲自参加并指导今年暑期社会实践活动，深入学生实践地具体开展各项指导工作，带领学生实践团队取得较好实践成效。在同等情况下，近几年内多次担任社会实践团队指导教师，且工作表现突出的，予以优先考虑。

3. 校级先进个人：面向参与2025年暑期大学生社会实践活动的在读浙江大学本科生。要求全程参加某一次社会实践活动，并在社会实践活动中表现突出；为当地经济社会等各项建设做出较大贡献；实践结束后认真总结，撰写2000字左右具有较高理论水平的实践报告。

4. 校级优秀论文：面向2025年暑期大学生社会实践所撰写的调查报告、学术论文、心得体会等。要求具有较高的思想性、艺术性和理论水平；格式参照《附件2：浙江大学大学生社会实践调研报告及论文格式样本》。

二、总结要求与材料上交

蒋玥+浙江大学竺可桢学院团委青志部赴内蒙古自治区鄂尔多斯市准格尔旗"竺光映北原·星火启心帆"暑期支教社会实践团队+2025暑期社会实践评优申报汇总表

1. 社会实践结题答辩时间暂定秋学期第一周，具体时间、地点及答辩场次另行通知。答辩形式为5分钟PPT展示与约3min评委提问，请各团队将总结册或调研报告打印三份，在答辩现场供评委审阅。

2. 各团队应制作好社会实践调研报告或总结册，并在**9月15日**前将答辩PPT、最终参与人员名单（excel表，包含姓名、学号等信息）、社会实践个人总结、调研报告或总结册、竺可桢学院2025学年暑期大学生社会实践活动团队材料汇总表（附件1）打包后发送至**Shijian_ckc@163.com** 。具体提交文件、命名格式要求如下：

① 答辩PPT（PPT格式）。命名格式【队长姓名+团队名称+答辩PPT】（本项“启真·燎原”必做，“海纳·筑疆”“开物·星火”可替换为微党课，“开物·星火”前往企业开展深度实践实习可提交实践周报等有关材料）。✅

② 最终参与人员名单（excel表，包含姓名、学号等）。命名格式【队长姓名+团队名称+最终名单】，格式参照附件5（本项为必做项）。✅

③ 个人总结（word格式，队伍所有人合在一个word）。命名格式【队长姓名+团队名称+个人总结】（本项为必做项）。✅

④ 队长下载并填写《竺可桢学院2025学年暑期大学生社会实践活动团队材料汇总表》（附件1）。命名格式为【队长姓名+团队名称+团队材料汇总表】（本项为必做项）。✅

⑤ 调研报告、总结册（pdf格式）。命名格式【队长姓名+团队名称+调研报告或总结册】，调研报告格式请参照附件2（“开物·星火”前往企业开展深度实践实习选做）。✅

⑥ 若有其他形式成果材料（如视频等。多个成果可单独打包命名），请命名为【队长姓名+团队名称+其他成果】。✅

⑦ 将所有资料压缩打包后命名为【队长姓名+团队名称+总结材料】，发送至**Shijian_ckc@163.com**，邮件命名为【队长姓名+团队名称+总结材料】。

注：部分实践团队涉密，①⑤两部分可仅提交微党课与总结册，评比将提高微党课所占权重。

3. 各团队应登录社会实践网络平台（网址：http://tzzd.zju.edu.cn）完成团队总结，通过总结评比审批流程上传实践《2025暑期社会实践评优申报汇总表》（附件3）。操作流程可见于附件4，网站开放上传时间另行通知，请各位队长及时关注钉钉群通知。

4. 社会实践考核表请完成除院系团委意见部分（小结部分做简要小结即可，要求手写），并于答辩会现场提交。

5. 鼓励实践团队于2025年新生军训期间进入军训连队进行以实践分享为主题的理想信念宣讲微党课，宣讲时间为8月25日——9月10日晚训期间（具体时间、地点与连队指导员协商）。请有意向进行理想信念宣讲的同学于**【8月27日24点前】**将报名回执（附件6）发送至**1193323713@qq.com**，邮件主题、文件命名为【姓名+卓越四团宣讲团报名回执表】。

注：

① 本项非必须项，实践成果辐射范围、宣讲质量将作为实践考评的重要项目。宣讲质量优先，四团政治处、各军训连队将严格把关宣讲质量。

② 理想信念宣讲以线下为主，如团队仍未返校且宣讲质量较好的，可考虑线上进行。
