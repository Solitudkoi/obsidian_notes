## 1. Opening

> Hi everyone, / I will focus on **why Attention is memory-bound** / and **how PIM can accelerate it**. //

### 这一句怎么讲

- **why Attention is memory-bound** 要重读
    
- **how PIM can accelerate it** 再次重读
    
- 这句不用快，开场稳住就行
    

---

## 2. Why Attention is Memory-Bound

> In LLM inference, / there are two major components: / fully connected layers / and Attention. //

> A key observation is that / **Attention is memory-bound** / rather than **compute-bound**. //

> There are **three reasons**. //

> First, / Attention is mainly based on **GEMV operations**, / not GEMM. /

> Second, / its arithmetic intensity is **very low**, / around one. /

> Third, / it requires repeatedly accessing / large **key-value matrices**. //

> So in practice, / the bottleneck is **not computation**, / but **data movement and memory bandwidth**. //

### 这一段的讲法提醒

这里最重要的是对比：

- **memory-bound**
    
- **compute-bound**
    
- **not computation**
    
- **data movement**
    

其中最后一句是核心，建议：

- “not computation” 稍微压一下
    
- “data movement and memory bandwidth” 明显重读
    

### 可配合动作

讲到 “three reasons” 时，可以轻轻举三根手指  
讲到 “key-value matrices” 时看一眼PPT

---

## 3. Why GPU is Inefficient

> [look at slide] In traditional GPU execution, / data flows from **DRAM** / to **GPU** / and back to **DRAM**. //

> This means / the key-value data is transferred repeatedly / across the memory interface. //

> As a result, / the system is limited by **bandwidth**, / not by **compute power**. //

> So the main issue with GPUs / is not that they cannot compute fast enough, / but that / **they cannot move data efficiently**. //

### 这一段的重音

重点压这几个词：

- **DRAM**
    
- **GPU**
    
- **bandwidth**
    
- **they cannot move data efficiently**
    

最后一句最好慢一点说，效果会很好。

---

## 4. How PIM Solves This

> Processing-In-Memory, / or **PIM**, / takes a different approach: //

> it **moves computation closer to data**. //

> [slow] Attention can be decomposed into **three steps**: //

> **Q times K transpose**, / **Softmax**, / and then multiplied by **V**. //

> In PIM, / these matrix-vector operations / are executed inside **DRAM banks**, /

> while Softmax / is handled by **buffer-level units**. //

> Most importantly, // **the key and value matrices remain inside memory** / during the entire process. //

> This avoids repeated data movement / between memory and compute units. //

### 这一段的讲法提醒

这段是你全程最重要的一段。

一定要突出两句：

- **it moves computation closer to data**
    
- **the key and value matrices remain inside memory**
    

第二句建议：

- “Most importantly” 后面停一下
    
- 然后慢速说完整句
    

这会显得你很会抓重点。

---

## 5. Conclusion + Transition

> In summary, //

> Attention is fundamentally limited / by **data movement**. /

> PIM addresses this / by performing computation **inside memory**, /

> which significantly reduces data transfer / and improves efficiency. //

> Next, / we will see / how to further optimize this / with dynamic scheduling. //

### 收尾技巧

- “In summary” 后面一定停顿
    
- **data movement**
    
- **inside memory**  
    这两个词一定重读
    

最后一句是和组员衔接，语气自然一点，不用太重。

# 救场句（忘词时直接用）

例如：

## 2. 忘了术语，但知道意思

> It relies on **GEMV**, has low arithmetic intensity, and repeatedly accesses large **KV matrices**.

> PIM solves this by **moving computation closer to data**.  
> Most importantly, **K and V remain inside memory**.  
> So PIM reduces data transfer and improves efficiency.
